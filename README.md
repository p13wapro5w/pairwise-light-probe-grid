# pairwise-light-probe-grid

角色走过走廊，身上的反光突然从暖色切成冷色，探针网格在三轴之间做三线性插值，没有按四面体权重分配；探针放在墙体内侧，室内光照漏到隔壁房间；动态物体只采样最近一个探针，经过门框时高光跳变；L1 球谐只存了直流项，金属反射失去方向性；探针更新按固定帧轮转，灯泡换色后整条走廊滞后半秒；遮挡探针没参与插值，桌子底下的物体被当成全亮；流式加载时探针体积边界没扩展，走到新区域采样返回零；多探针重叠区域权重没归一化，能量翻倍；镜面反射用漫反射探针近似，光滑地面出现一团糊光；探针数据用 8bit 存辐照度，HDR 窗边过曝成纯白。render/light_probe_grid.py 是核心，tests/test_light_probe_grid.py 15个红。要修的是：四面体插值；探针可见性标记；动态物体多探针混合；球谐补方向项；更新按重要性；遮挡探针剔除；流式边界扩展；权重归一；镜面单独探针；HDR 浮点存储。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。

子方向：见平台；任务类型：Bugfix；语言/框架：Python 3, pytest；环境可复现等级：无外部依赖。
